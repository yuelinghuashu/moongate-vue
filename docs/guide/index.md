# 介绍

## 什么是 Moongate Vue？

Moongate Vue 是一个受月亮启发的**极简 Vue 3 组件库**。设计令牌驱动，CSS 优先，框架无关。

**完整组件库（JS + CSS）仅 25KB (gzipped)**。

## 特性

- 🌙 **月亮哲学** — 克制、冷静、秩序感
- 📦 **极致轻量** — 完整组件库（JS + CSS）仅 25KB
- 🎨 **设计令牌驱动** — CSS 变量，深色/浅色模式无缝切换
- 🔧 **CSS 优先** — 样式与逻辑解耦，可跨框架复用
- ✨ **极简 API** — 绝大多数组件 2-8 个 props（少数复杂组件如 Button/Select 略多）
- 🚀 **零依赖** — 开箱即用

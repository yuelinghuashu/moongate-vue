# 介绍

## 什么是 Moongate Vue？

Moongate Vue 是一个受月亮启发的**极简 Vue 3 组件库**。设计令牌驱动，CSS 优先，框架无关。

**完整组件库仅 10KB (gzipped)**，比主流组件库轻 10 倍以上。

## 特性

- 🌙 **月亮哲学** — 克制、冷静、秩序感
- 📦 **极致轻量** — 完整组件库仅 10KB
- 🎨 **设计令牌驱动** — CSS 变量，主题切换 effortless
- 🔧 **CSS 优先** — 样式与逻辑解耦
- ✨ **极简 API** — 每个组件 2-8 个 props
- 🚀 **零依赖** — 开箱即用
